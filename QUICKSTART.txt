CONVERTTEXTURE PRO — QUICK START

1. Install Node.js 20+.
2. Extract project.
3. Open terminal in this folder.
4. Run: npm start
5. Open: http://localhost:3000

Production:
- Set NODE_ENV=production
- Set SESSION_SECRET to a long random value
- Mount the data/ folder as persistent storage
- Deploy to Render, Railway, Docker, VPS, or a Node-capable panel

Important:
This is a full-stack website. Static Netlify deployment cannot provide secure login, persistent quota, or admin queue without an external backend/database.
